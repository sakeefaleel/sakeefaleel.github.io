SAKEE FALEEL — PORTFOLIO WEBSITE

Files:
- index.html: page content
- style.css: layout and responsive styling
- script.js: mobile navigation and footer year
- assets/: place optional images here

PUBLISH WITH GITHUB PAGES
1. Extract this ZIP.
2. In GitHub, open the repository that currently publishes your site.
   For https://sakeefaleel.github.io, the usual repository name is sakeefaleel.github.io.
3. Clone that repository to your Mac, or open your existing local clone.
4. Copy the CONTENTS of this folder into the repository root, replacing the old index.html, style.css and script.js. Do not delete the .git folder.
5. In Terminal, from inside the repository:
   git status
   git add .
   git commit -m "Update portfolio content and experience"
   git push
6. In GitHub, check Actions and Settings > Pages. Once deployment finishes, refresh the website.

Before publishing:
- Confirm all listed certifications are completed and accurate.
- Confirm contact details and experience dates.
- This version does not display date of birth, for privacy.
- No CV download button is included because no CV file was bundled.
